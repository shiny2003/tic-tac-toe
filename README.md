A simple Tic-Tac-Toe game developed using Python. This is a two-player game where players take turns marking X and O on a 3×3 board. The program checks for a winner or a draw.
# Tic-Tac-Toe Game using Python

## Description
This is a simple two-player Tic-Tac-Toe game developed using Python.

## Features
- Two-player game.
- Player 1 uses X.
- Player 2 uses O.
- Checks the winner.
- Displays a draw if nobody wins.

## Technologies Used
- Python

## How to Run
1. Download the Python program.
2. Open it in Python or Google Colab.
3. Run the program.
4. Enter positions from 1 to 9 to play.

## Game Board

1 | 2 | 3
4 | 5 | 6
7 | 8 | 9
